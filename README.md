# Relatório Técnico - ACBr

Este repositório contém o relatório técnico desenvolvido para a disciplina de **Desenvolvimento de Sistemas (M-Tec)** na **Etec Vereador Valdivino Antônio Marcusso**.

O objetivo do trabalho foi analisar o sistema comercial de um mercado, identificar falhas na rotina do caixa e propor melhorias utilizando o ecossistema **ACBr**.

## 📌 O que foi analisado:
* **Problema:** Uso de maquininha de cartão separada do sistema (POS), gerando risco de erros de digitação.
* **Solução:** Integração do sistema de gestão com o **ACBrMonitorPLUS** para automatizar os pagamentos (TEF) e a comunicação com a balança Toledo e a impressora Tanca.
